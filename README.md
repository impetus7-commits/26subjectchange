# 2027 수강신청 변경 검토 시스템

HScredit(고교학점제 수강신청 프로그램)의 **수강신청 일괄등록 엑셀**을 올려 학생별 2027학년도 1·2학기 수강신청 변경을 입력·검토·승인하고, 승인 결과를 **같은 양식의 일괄등록 파일**로 다시 내려받는 웹페이지입니다.

- **파일 하나(`수강변경검토(YYMMDDHHmm).html`, 괄호 안은 만든 날짜·시간)로 동작**합니다. 더블클릭해서 열면 되고, 인터넷이 없어도 됩니다(엑셀 처리 도구 내장).
- 학생 자료는 **이 컴퓨터의 브라우저 안에만** 저장됩니다. 서버로 보내지 않습니다.

## 학년·학기

| 화면의 학년 | 대상 | 변경하는 학기 | 참고로만 보는 학기 |
|---|---|---|---|
| 2학년 | 2026학년도 입학생 파일 | 2-1, 2-2 | – |
| 3학년 | 2025학년도 입학생 파일 | 3-1, 3-2 | 2-1, 2-2 (중복 이수 점검용) |

화면 위 **[학년] [학기]** 버튼으로 고르면 모든 화면이 그 학년·학기 기준으로 바뀝니다. **[1·2학기]** 를 고르면 두 학기를 한꺼번에 봅니다.

## 화면

| 메뉴 | 하는 일 |
|---|---|
| 📊 과목별 현황 | 선택군별 과목 인원(최초 → 승인 반영, 검토 대기 변동), 최소 개설 인원 미달·0명 과목 표시. 과목을 누르면 명단 |
| 🧑‍🎓 학생별 변경 | 학생 검색(이름·학번·반) → 과목 단추를 눌러 변경 → 사유 입력 → **검토 대기로 저장** 또는 **바로 승인**. 저장 전에 선택군 과목 수·같은 과목 중복을 검사하고, 바뀌는 과목의 예상 인원을 보여 줌. 학생 변경 확인서 인쇄 |
| 📝 변경 신청 목록 | 검토 대기/승인/반려별 목록, 승인·반려(사유)·되돌리기·삭제, 한꺼번에 승인. 검토 대기 화면 위에 **'모두 승인하면 인원이 바뀌는 과목'** 표(현재 인원 → 승인 후 인원, 증감, 학급 수 변화, 기준 미달·정원 초과) |
| 📋 명단·반별 | 과목별 수강생 명단(유지/추가/빠짐), 명단 인쇄, **반별 변경 신청 인원**(반별 신청 학생 수, 과목별 +넣는/−빼는 학생 수, 승인+검토 대기) |
| ⚠️ 규칙 점검 | 승인 반영 기준으로 규칙에 어긋나는 학생 목록 |
| ⚙️ 파일·설정·내보내기 | 파일 올리기, **HScredit 일괄등록 파일(승인 반영)**·변경 내역·과목별 인원표 엑셀, 작업 백업 저장/불러오기, 최소·최대 인원, 선택군 규칙 |

## 규칙

- **선택군 과목 수**: 파일의 신청 내용에서 자동으로 알아냅니다(예: 3-2 G군 7과목). [설정]에서 고칠 수 있습니다.
- **같은 과목 중복 신청 금지**: 이름이 같은 과목을 두 학기에 신청하면 막습니다(예: 2-1·2-2 C군 같은 제2외국어, 3-1·3-2 '운동과 건강').
- **인원**: 최소 개설 인원(기본 13명) 미만, 과목 최대 인원 초과를 경고합니다.
- **서술형 규칙**: [설정 → ✍️ 서술형 규칙]에 한 줄에 하나씩 문장으로 씁니다. 문장 속 과목 이름과 낱말로 자동 해석하고, 해석 결과와 위반 학생 수를 표로 보여 줍니다.
  - 조건: "미적분Ⅱ를 선택하면 기하도 선택해야 한다" / "A 선택 시 B 선택 불가"
  - 선수 과목: "미적분Ⅱ를 선택하려면 이전 학기에 기하를 이수해야 한다"
  - 개수: "경제, 법과 사회, 도시의 미래 탐구 중 최대 2과목" / "중 1과목 이상" / "중 1과목만"
  - 함께 불가: "생물의 유전과 지구시스템과학은 함께 선택할 수 없다"
  - 필수: "실용 통계는 필수" / "A 또는 B 필수"
  - '권장·추천·가급적'이 있으면 경고(저장 가능), 없으면 오류(저장 막음). 과목을 못 찾은 문장은 '안내'로만 표시. 같은 이름 과목은 "3-1 운동과 건강"처럼 학기를 붙임. '#'으로 시작하면 메모
- **학급 수**: 과목 인원 ÷ 학급당 정원(기본 25명)을 올림한 값입니다. [설정]에서 정원을 바꿀 수 있습니다.

## 상태 설명

- **최초 신청**: 올린 파일 그대로
- **승인 반영**: 최초 신청 + 승인된 변경 → 내려받는 HScredit 파일의 내용
- **검토 대기 포함**: 승인 반영 + 아직 검토하지 않은 변경 (예상 인원)

## 고치는 법 (개발용)

- 화면 원본은 `src/index.html`, 엑셀 도구는 `vendor/xlsx.mini.min.js`(SheetJS 0.18.5, Apache-2.0)
- `node build/build.js` 를 실행하면 둘을 합쳐 `index.html` 과 배포용 `dist/수강변경검토(YYMMDDHHmm).html`(괄호 안은 만든 날짜·시간)을 만듭니다.
